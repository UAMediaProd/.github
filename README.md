# Adelaide University Media Production

**Media Production · Teaching & Learning Innovation · Adelaide University**

We build custom educational interactives, animations, and tooling for academic teaching. Most of what's here is either a Vue/Vite interactive embedded in Canvas, or something that helps us make those faster and better.
